# 対象

第9章「利用者の入力はそのまま HTML にしない」

# 総評

Sinatra の ERB に自動エスケープを期待しない説明になっており、`Rack::Utils.escape_html` への依存も明示されている。技術的に誤解を招きにくい。

# 良い点

- `h` ヘルパーの実装が本文に示されている。
- ERB の `<%= %>` は値を出力するものであり、安全化ではないと説明している。
- 危険なコードは一時的な確認に閉じる方針が明確である。
- `textarea` の終了タグを使った例が含まれている。

# 改善が必要な点

## must

なし。

## should

- 問題: `Rack::Utils.escape_html` が HTML 用のエスケープであり、すべての文脈に万能ではないことを軽く補足した方がよい。
- 理由: JavaScript 文字列や URL など、別文脈にもそのまま使えばよいという誤解を避けるため。
- 修正案: 本書で扱う HTML 本文・属性値・textarea の範囲で使う、と明記する。

## could

- 改善案: CGI.escapeHTML との比較は不要。
