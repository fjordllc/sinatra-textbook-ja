# 対象

第10章「見つからないものには 404 を返す」

# 総評

404 ページは簡潔で、一覧へ戻る導線がある。`layout.erb` の役割を崩していない点もよい。

# 良い点

- 404 ページに主要導線として映画一覧へのリンクがある。
- 個別 ERB に `html` や `body` を書かない説明がある。
- 画面だけでなくステータスコードを見る説明がある。

# 改善が必要な点

## must

なし。

## should

- 問題: 404 ページの文言が「ページ、または映画」とやや抽象的である。
- 理由: 存在しない URL と映画 ID の両方に使うには妥当だが、読者に「なぜ同じ画面でよいのか」を補足してもよい。
- 修正案: 本書では共通の 404 ページを使い、詳細な出し分けは扱わないと説明する。
