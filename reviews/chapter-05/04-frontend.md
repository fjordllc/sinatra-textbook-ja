# レビュー担当

フロントエンドエンジニア

# 対象

第5章「JSON ファイルに映画を保存する」

# 総評

フォームの構造、ラベル、入力値の保持、エラーメッセージの表示は基本に沿っている。`textarea` の値の入れ方や `select` の `selected` の扱いも、初学者に必要な範囲で説明されている。

# 良い点

- `label` とフォーム部品の `id` が対応している。
- 入力エラー時に、監督、公開年、ジャンル、紹介文が保持される。
- `textarea` は `value` 属性ではなく、要素内容へ値を入れる説明がある。
- エラーメッセージがフォーム上部に表示され、CSS で視認できる。
- 一覧の表示値とフォームに戻す値の両方で `h` を使っている。

# 改善が必要な点

## must

なし。

## should

- 問題: エラーメッセージ領域に `role="alert"` などのアクセシビリティ属性はない。
- 理由: 本章の主目的ではないが、エラー表示としては補助技術へ伝わりやすい形にできる。
- 修正案: 詳細なアクセシビリティ説明までは入れず、完成コードの `.error-messages` に `role="alert"` を付けるか、第5章では扱わないと明記する。

## could

- 改善案: `select` の初期値が未選択ではなく最初の項目になることを短く説明してもよい。
- 期待される効果: タイトルだけ必須にしていることとの違いが分かりやすくなる。

# 疑問点

- 本格的なアクセシビリティ説明は範囲外でよいが、エラー表示の最低限の構造は崩さない方針を維持したい。
