# 総評

HTML を「画面」ではなくレスポンス本文として捉え直す説明が、後のフォームと XSS の学習へつながります。静的ファイル、Web サーバーから返す静的 HTML、Ruby が作る HTML の三つを分けた点は、フロントエンドとサーバー側の責務を単純な二分法にしていません。mdBook のデスクトップ表示と狭い幅での表示にも重大な崩れはありません。

# 良い点

- ブラウザが HTML を解釈して表示する役割と、サーバー側で HTML を用意する役割を区別している。
- JavaScript を使う構成も存在すると断った上で、本書の範囲を限定している。
- 図 1-1 は色だけでなく、ラベルと矢印方向でリクエストとレスポンスを区別している。
- SVG に `aria-label` があり、Markdown 側にも内容を表す代替テキストがある。
- 表には見出しセルがあり、mdBook のラッパーによって狭い画面では横スクロールできる。
- Network パネルで `Response` の HTML とレンダリング結果を比較させる観察が適切である。
