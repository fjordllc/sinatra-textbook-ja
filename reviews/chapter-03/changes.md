## 採用しなかった指摘

### 指摘: `erb :index` と文字列引数の違いを補足する

- 出典:
  - `03-ruby-sinatra.md`
- 理由: Sinatra の `erb` に文字列を渡す挙動は正確だが、この章の主題は `views/` に置いたテンプレートを使うことにある。ここで引数の種類を増やすと、初学者の注意が散るため採用しない。

### 指摘: 第3章で `h` ヘルパーを導入する

- 出典:
  - レビュー統合時の検討
- 理由: 本書の方針では `h` ヘルパーは第6章で安全な表示の基準として導入する。第3章では固定データであることと、利用者入力にはエスケープが必要になることだけを説明する。

## 新たな設計判断

- 第3章では、狭幅表示への最低限の対策として `.table-scroll` を導入する。ただし CSS の詳細解説には広げない。
- 第3章の完成コードには、`app.rb` だけでなく ERB と CSS の最終形も掲載する。今後の章でも、ビューやフォームが主題の章では章末の照合対象に含める。
- `Content-Type` の観察では、実測値をもとに `text/html` と `text/css` を例示するが、細かな charset の有無は環境差を許容する表現にする。
