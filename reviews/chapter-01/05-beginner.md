# 改善が必要な点

## must

### DevTools を開くところで手が止まる

- 対象: `manuscript/part1/chapter1.md:153`
- 分からなかったこと: Chrome で DevTools をどう開くのか書かれていません。Network パネルを使った経験がない場合、最初の手順を実行できません。
- 修正案: macOS では `Command + Option + I`、Windows/Linux では `Control + Shift + I` と書き、開いた後に `Network` を選ぶところまで示してほしいです。

### 本書をファイルとして開いた場合の進め方が分からない

- 対象: `manuscript/part1/chapter1.md:151`
- 分からなかったこと: アドレスバーが `file://` のときにも、`Request Method` と `Status Code` が本文どおり見えるのか判断できません。
- 修正案: `http://` または `https://` で開いているページを使うと明記し、`file://` の場合に使う URL を案内してほしいです。
