Ruby・Sinatra・Rack に詳しい技術者

# 対象

第10章「見つからないものには 404 を返す」

# 総評

Sinatra の `not_found` と、ルート内で `status 404` を返す方法が初学者向けに分かりやすく使われている。500 の扱いも本格的な例外処理へ広げず、観察に留めている。

# 良い点

- `not_found do erb :not_found end` が存在しない URL に使われている。
- 既存の ID 検索で `nil` の場合に 404 を返している。
- 500 の確認用ルートを一時的なものとして扱っている。

# 改善が必要な点

## must

なし。

## should

- 問題: `not_found` ハンドラーと、ルート内の `status 404; return erb :not_found` の使い分けが少し分かりにくい。
- 理由: 読者が「全部 not_found に任せればよいのでは」と思う可能性がある。
- 修正案: ルートには一致したが、その中で映画が見つからない場合はアプリ側で 404 を返す、と補足する。
