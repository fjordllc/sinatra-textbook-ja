# 総評

# 良い点

- `load_movies` と `save_movies` の実コードを使って、ファイル全体の読み書きを説明している。
- `find_movie` が配列を順番に探すことを、データ量の話へ接続している。
- Active Record を、Ruby オブジェクトとデータベースの対応として簡潔に説明している。
- データベースの導入手順や SQL に踏み込んでいない。
