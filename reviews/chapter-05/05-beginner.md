# 改善が必要な点

なし。

## should

- 問題: `JSON.parse` と `JSON.pretty_generate` の違いを、コードを見ただけでは混同しそうである。
- 理由: どちらも `JSON.` で始まるため、読み込みと書き込みで逆に使ってしまう可能性がある。
- 修正案: 「`parse` は JSON 文字列を Ruby へ、`pretty_generate` は Ruby を JSON 文字列へ変換する」と一文で対比する。

## could

- 期待される効果: フォーム初期表示のコードを怖がらず読める。
