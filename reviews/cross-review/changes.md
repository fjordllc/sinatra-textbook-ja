# 横断レビュー修正記録

## 対応した指摘

### 部の導入プレースホルダー

#### 指摘

第2部、第3部、第4部の index にプレースホルダーコメントが残っていた。

#### 対応

各部の導入文を追加した。各部で扱う章と、その部で読者が学ぶ流れを短く説明した。

#### 理由

本文を公開する状態で、執筆途中のコメントを残さないため。部の導入により、読者が現在地を把握しやすくなるため。

### RFC 9110 のリンク

#### 指摘

付録Eの RFC 9110 URL が外部リンク検査で 404 になった。

#### 対応

RFC Editor の info ページである `https://www.rfc-editor.org/info/rfc9110` へ変更した。

#### 理由

外部リンク検査で到達可能な公式ページへ誘導するため。

## 採用しなかった指摘

### 第11章・第12章への図版追加

#### 指摘

第11章や第12章にも図版を追加できる。

#### 理由

第11章はデバッグ時に見る境界を表で整理しており、第12章は保存方式の限界を文章とコードで振り返る章である。図版追加は現時点の理解に対して必須ではなく、制作コストに比べて効果が小さいため採用しなかった。

### RuboCop と ERB Lint の Gemfile 追加

#### 指摘

付録で扱う RuboCop と ERB Lint を、このリポジトリの `Gemfile` に追加して実行できるようにしてもよい。

#### 理由

付録は本編の必須手順ではない。サンプルアプリの固定技術構成を広げるより、必要になった段階で導入例として示す方が本書の範囲に合うため採用しなかった。

## 新たな設計判断

- 付録は本編の完成コードに影響しない補助章として扱う。
- 横断レビューでは、章ごとの 6 観点レビューを再実施するのではなく、全体の整合性、公開状態、検証結果を確認する。
