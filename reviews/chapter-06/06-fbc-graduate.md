# 対象

第6章「一覧と詳細でリソースを分ける」

# 総評

REST の理論を深掘りせず、URI が何を指すかをコードで理解する章になっている。Rails に進む前に、一覧と詳細が単なる画面分割ではなくリソースの違いであることを学べる点がよい。

# 良い点

- 登録後の詳細リダイレクトにより、作成したリソースを見る流れが自然になっている。
- 404 を早い段階で導入し、見つからないものを通常処理に混ぜない姿勢がある。
- `white-space: pre-line` により、Ruby で HTML を生成する悪い癖を避けている。
- 第7章の編集・削除へ、1 件の映画を ID で扱う前提を渡せている。
