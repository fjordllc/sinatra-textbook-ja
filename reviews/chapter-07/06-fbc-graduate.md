# 対象

第7章「編集と削除で CRUD を完成させる」

# 総評

FBC 受講時に混乱しやすい method override と PATCH/DELETE の観察方法が、かなり実践的に説明されている。Rails に進む前に、HTML フォームと Rack の関係を体験できる章になっている。

# 良い点

- Network タブでは POST、Sinatra ログでは PATCH/DELETE という違いを明示している。
- 削除を GET リンクにしていない点がよい。
- 更新・削除でも 404 を扱い、存在しない ID を通常処理に混ぜていない。
- CSRF や削除確認など範囲外の話を広げすぎていない。
