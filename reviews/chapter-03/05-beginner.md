# 改善が必要な点

## must

### 最後に完成したビューのコードを見たい

- 問題: 3.10 で `app.rb` は確認できるが、`views/layout.erb` と `views/index.erb` と CSS の最終形が分からない。
- 問題になる理由: 途中のコードを全部正しく反映できたか、自分だけでは判断できない。
- 修正案: 3.10 に完成版の `views/layout.erb`、`views/index.erb`、CSS を載せる。
- 対象箇所: 3.10

## should

### 第3章をどこから始めるかが分かると安心

- 問題: すでに第2章から続けている人は分かるが、途中から始める場合のコマンドがない。
- 問題になる理由: `chapter-02` から始めればよいのか、`main` でよいのか迷う。
- 修正案: 冒頭に `git switch -c chapter-03-work chapter-02` のような開始方法を短く書く。
- 対象箇所: 章冒頭

### `movies` をどこに書くかをもう少し強調してほしい

- 問題: 「`require "sinatra"` の下に追加」と書いてあるが、長いコードなので場所を間違えそう。
- 問題になる理由: `get "/movies"` の中に入れてしまうかもしれない。
- 修正案: `movies` はルート定義より前に置く、と一文加える。
- 対象箇所: 3.5

## could

- 期待される効果: `end` の書き忘れなどで止まったときに切り分けやすい。
- 対象箇所: 3.5 付近
