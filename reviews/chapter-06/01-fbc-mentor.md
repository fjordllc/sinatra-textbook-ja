# レビュー担当

FBC ベテランメンター

# 対象

第6章「一覧と詳細でリソースを分ける」

# 総評

一覧と詳細をリソースの単位で分ける目的が明確で、FBC の REST 学習から Sinatra 実装へつなげる章として自然である。存在しない ID への 404 も、後の 404 ページへ進む足場として適切である。

# 良い点

- `/movies` と `/movies/:id` の違いを画面名ではなく集合と 1 件の違いとして説明している。
- 一覧に全項目を出さず、詳細画面に監督と紹介文を置く理由が自然である。
- `halt 404` により、存在しない ID を通常画面として扱わないことを学べる。
- 登録後の遷移先を詳細へ変え、操作結果を確認しやすくしている。
- `white-space: pre-line` を使い、Ruby で `<br>` を生成しない方針が入っている。

# 改善が必要な点

## should

- 理由: FBC でもルート順による誤動作はつまずきやすい。
- 修正案: 完成コードの前後に「具体的なルートを先、変化するルートを後」と一文足す。
