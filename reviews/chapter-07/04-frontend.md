# レビュー担当

フロントエンドエンジニア

# 対象

第7章「編集と削除で CRUD を完成させる」

# 総評

編集フォームと削除フォームの HTML は基本に沿っている。削除ボタンがフォームで実装されており、リンクで削除しない点もよい。

# 良い点

- 編集フォームの `label` と入力欄の対応が登録フォームと同様に保たれている。
- `_method` を hidden input としてフォーム内に置いている。
- 削除はリンクではなくフォームとボタンで表現している。
- 削除ボタンに視覚的な区別がある。
- 詳細画面に一覧、編集、削除の導線がまとまっている。

# 改善が必要な点

## must

なし。

## should

- 問題: 詳細画面のアクション領域で、リンクとボタンが混在しているため、キーボード操作や視覚上の一貫性が少し弱い。
- 理由: 初学者向けでも、主要操作のグルーピングを分かりやすくした方がよい。
- 修正案: `page-actions` の説明を本文に入れ、CSS でフォームの余白をなくして横並びにする意図を示す。実装はすでに近い。

## could

- 改善案: 削除ボタンの `danger-button` は説明しすぎなくてよい。
