# 総評

編集画面を表示する GET と、更新する PATCH の違いは分かりやすい。`_method` の説明も、Network タブでは POST と見えることが書かれているので混乱しにくい。

# 良い点

- 表示するだけの GET と、変更する PATCH の違いが具体的である。
- `hidden` の `_method` が何のためにあるか分かる。
- タイトルを空にしたときに保存されないことが書かれている。
- 削除後に一覧へ戻る理由が分かりやすい。

# 改善が必要な点

- 問題: `merge` と `merge!` の違いが分からない読者がいそうである。
- 理由: この章で更新処理の中心になるため、どちらが新しいハッシュを作り、どちらが元のハッシュを書き換えるのかを知りたい。
- 修正案: `merge` と `merge!` の違いを短く補足する。

## could

- 改善案: 削除後に元の詳細 URL へアクセスすると 404 になることを確認項目に入れてもよい。
