# レビュー担当

FBC ベテランメンター

# 対象

第10章「見つからないものには 404 を返す」

# 総評

404 を画面表示ではなく HTTP ステータスとして扱う点が明確で、FBC のレビューで重視する観点に合っている。映画図鑑の完成状態を確認する節も、次のデバッグ章へ進む前の節目として有効である。

# 良い点

- 存在しない URL と存在しない映画 ID を分けて扱っている。
- 詳細・編集・更新・削除の各入口で 404 を返す方針がある。
- `layout.erb` と個別 ERB の役割に触れている。
- 404 と 500 の違いを Network タブで確認する構成になっている。

# 改善が必要な点

## must

なし。

## should

- 問題: `status 404; return erb :not_found` が複数ルートに重複している。
- 理由: 初学者教材としては許容できるが、同じ処理が繰り返される理由を明示した方がよい。
- 修正案: この章では読みやすさを優先して重複を残し、整理は後のリファクタリング対象になり得ると短く補足する。
