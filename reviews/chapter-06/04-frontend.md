# レビュー担当

フロントエンドエンジニア

# 対象

第6章「一覧と詳細でリソースを分ける」

# 総評

一覧、詳細、戻る導線が分かりやすく、HTML の構造もおおむね妥当である。説明用の小さなアプリとして過度な装飾に寄っていない。

# 良い点

- 一覧に「操作」列を追加し、詳細リンクを明示している。
- 詳細画面に `<dl>` を使い、属性名と値の関係を表している。
- 戻るリンクがあり、ブラウザバックに依存していない。
- 紹介文の改行を CSS の `white-space: pre-line` で扱っている。
- 詳細画面の各値が `h` でエスケープされている。

# 改善が必要な点

## must

なし。

## should

- 問題: `.movie-detail div` にグリッドを当てているが、狭い画面で 120px + 1fr の横並びが窮屈になる可能性がある。
- 理由: 初学者教材でも、スマートフォン幅で読みにくい表示は避けたい。
- 修正案: メディアクエリで狭幅時に 1 列表示へ切り替える。

## could

- 改善案: 詳細リンクの文言を「詳細」から「詳細を見る」にすると操作が少し明確になる。
