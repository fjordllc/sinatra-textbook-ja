# 総評

第5章で導入した `h` ヘルパーの意味を、危険な表示との比較で理解する章になっている。前章までの実装を壊さずに意味付けする流れもよい。

# 良い点

- 冒頭で前章からの接続と、この章の目的が分かる。
- 安全な状態で確認してから、危険な状態を一時的に作る順序がよい。
- 「この章の完成コードに変更はない」と明記されている。
- 章末の確認項目が本文の流れと対応している。

# 改善が必要な点

なし。

## should

- 問題: XSS の説明で「意図しない HTML や JavaScript」とあるが、なぜ JavaScript だけでなく HTML と書くのか補足があるとよい。
- 理由: XSS を script タグだけの問題と捉えない章の狙いと合う。
- 修正案: 「タグ構造や属性を壊すことも問題になる」と一文足す。

- 改善案: 用語「文字参照」は第5章でも出ているため、ここでは簡潔でよい。
